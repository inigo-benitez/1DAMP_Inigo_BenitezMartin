__¿Qué es un programa informático?__


###Un programa informático es una serie de instrucciones que le decimos al ordenador para que haga algo. Puede ser algo sencillo, como una calculadora, o algo mucho más complicado, como el sistema operativo de tu móvil. Nosotros escribimos lo que qué queremos que haga con un lenguaje que el ordenador pueda entender, y él lo va a ejecutar paso a paso.


__ Diferencia entre código fuente, código objeto y código ejecutable.__


### Código fuente: es lo que escribe el programador. Algunos ejemplos son: Java, Python o C++.

### Código objeto: es una versión que el ordenador ya empieza a entender, pero que todavía no puede usarse por sí sola.

### Código ejecutable: es el programa ya terminado y listo para abrirse, por ejemplo cuando haces doble clic en una aplicación.


__ Etapas del desarrollo del software.__


### Las etapas del desarrollo de software son los pasos que se siguen para crear un programa. Primero se piensa que se va a programar, teniendo en cuenta que esto se adapte a lo que necesite el usuario. Después se escribe el código, y se comprueba que todo funcione. Por último se corrigen posibles fallos, o se hacen mejoras.
